# Kit Sólidos Geométricos

Página de vendas responsiva do Kit Sólidos Geométricos, com mockup do produto, carrossel de entregáveis, demonstrações de uso, bônus, ofertas, garantia e FAQ.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Publicar na Vercel

Importe este repositório na Vercel. O projeto usa Next.js e não precisa de configuração adicional de build.

## Produção

```bash
npm run build
npm start
```
